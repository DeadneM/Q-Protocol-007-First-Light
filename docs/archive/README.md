# Q Protocol archive

This directory preserves historical research and build notes that are no longer part of the active Q Protocol architecture.

For the current project state, always read:

1. `/PROJECT_STATE.md`
2. `/docs/STATUS.md`
3. `/README.md`

Archived files may describe gadget support, old AUTO state machines, old game executable layouts, or rejected compatibility branches. They are retained as technical evidence only and must not be treated as current implementation guidance.

## Archived material

- `GADGET_IDENTITY_AUDIT_U77.md` — historical gadget identity research.
- `U67_DELTA.md` — historical U57/U60/U67 gadget-era delta audit.
- `U49_PATCH.md` — historical U33 -> U49 binary patch record.
- `RELEASE_U49.md` — historical U49 prerelease notes.
- `QProtocol_U74_LEGACY.ini` — legacy cumulative configuration before the minimal-core reset.

The corresponding historical U49 builder is preserved under `/tools/legacy/build_u49.py`.
