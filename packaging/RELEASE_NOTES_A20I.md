# Q Protocol v0.9.3 — Fresh Core A20I

Small feature and usability release built on the validated A20F post-update core.

## Changes

- Added a **Weapons** tab for configuring Weapon 1-8 / F5-F12.
- Renamed the previous catalogue / Spawn Weapon / Runtime Discovery area to **Debug**.
- F1 now observes the game's native **License To Kill** state and forces the opposite state at press time.
- Preserved the validated direct native `ItemEntry/Spawner` weapon architecture.
- Preserved Manual loadout, AUTO, ammo, Q-Pistol swap and the validated 31-weapon catalogue.

## Note

`Debug -> Spawn Weapon` remains a diagnostic tool. Normal story-mode gameplay state can interfere with immediate weapon equipping.
